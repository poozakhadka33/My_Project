# Online Food Ordering System

## Project Overview

The Online Food Ordering System is a web-based application designed to support online food ordering and restaurant management. Customers can browse available food items, add items to a shopping cart, manage their orders, and choose between Cash on Delivery (COD) and online payment options.

The application also includes restaurant management functionality, allowing authorized users to register or log in as managers and manage food listings, update orders, and view order details.

Built using PHP, SQL, JavaScript, and Bootstrap, the project combines front-end design, server-side processing, and database integration to support an online food ordering workflow.

## Project Objectives

- Develop a web application for online food ordering.
- Implement customer registration and login.
- Allow customers to browse food items and manage their shopping cart.
- Support checkout options, including Cash on Delivery and online payment.
- Provide manager registration and login functionality.
- Enable food management and order administration.
- Store and retrieve application data through an SQL database.

## How the Application Works

1. Customers register or log in to access the ordering functionality.
2. They browse the available food items and add selections to the cart.
3. Customers update their cart before proceeding to checkout.
4. They select an available payment method and submit their order.
5. Restaurant managers log in to manage food items and view or update orders.
6. The application uses PHP and the SQL database to process and manage the information required by these workflows.

## How to Run

The following steps provide a general setup guide. Adjust them to match the database and configuration used in your project.

1. Install a local development environment such as XAMPP with PHP, a web server, and the appropriate database server.
2. Clone or download this repository.
3. Place the project folder in the web server's document directory.
4. Start the web server and database service.
5. Import the project's SQL file into the database management tool.
6. Update the database connection settings in the PHP configuration file.
7. Open the application through your local server in a web browser.
