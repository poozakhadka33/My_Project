# Airline Passenger Satisfaction Analysis

## Project Overview

This project explores airline passenger satisfaction using data analysis and machine learning. The goal was to investigate customer satisfaction patterns, identify important associated factors, and compare classification models.

## Objectives

- Explore passenger demographics, travel characteristics, and service ratings.
- Identify variables associated with passenger satisfaction.
- Compare machine learning models for satisfaction classification.
- Communicate findings in a clear and understandable way.

## Dataset

- **Records:** 129,880 passenger records
- **Variables:** 23 demographic, service, and operational variables
- **Analysis focus:** Passenger satisfaction and customer experience

## Tools and Technologies

- Python
- pandas and NumPy
- scikit-learn
- Exploratory data analysis
- Statistical analysis and model evaluation
- Data visualization

## Methodology

1. Prepared and explored the passenger dataset.
2. Examined satisfaction patterns across customer and service characteristics.
3. Developed and compared Random Forest, Decision Tree, and Logistic Regression models.
4. Evaluated model performance using classification metrics and validation techniques.
5. Examined feature importance to identify variables associated with satisfaction.

## Key Findings

The analysis explored the relationship between passenger satisfaction and service experience. Factors such as online boarding, seat comfort, and in-flight entertainment were among the important features identified in the analysis.

These findings indicate associations in the dataset and should not be interpreted as proof of causation.
